For administrators

The daily roster workflow

Full checklist ↗
  1. 01 / EXPORT

    Save yesterday’s roster

    In the private app, open Data Hub → Replace entire roster. Export the current roster to your team’s private archive.

  2. 02 / PREVIEW

    Check today’s workbook

    Select the complete .xlsx file and preview it. Compare the employee and placement counts. Cancel if anything looks wrong.

  3. 03 / VERIFY

    Replace and verify

    Type REPLACE and confirm the import. Check the new count on the Dashboard and find a known ID in Employee Directory.

Only have corrections? Use Upload a daily dataset instead. That merges changes without deleting employees missing from the file.
